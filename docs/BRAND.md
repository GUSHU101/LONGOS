# LONGOS 品牌规范

本文档是 LONGOS 产品身份的唯一规范来源。平台配置以 `config/longos.php` 为机器可读事实源；租户商城品牌属于租户数据，不得反向覆盖 LONGOS 控制面身份。

## 品牌定义

- 正式名称：LONGOS
- 产品名称：LONGOS Commerce SaaS
- 归属标识：LONGOS
- 品牌主张：一个平台，运营每一个独立站。
- 英文主张：One platform. Every storefront.
- 定位：为品牌方、跨境团队、服务商和多站点运营商提供可规模化交付的多租户电商基础设施。
- 核心差异：租户强隔离、批量自动化、域名所有权验证、统一控制面、租户白标前台。

## 核心价值

1. 隔离可信：租户上下文必须明确、可审计、失败关闭。
2. 自动交付：把建站、域名、初始化和运维转化为可重复流程。
3. 长期可控：优先使用稳定边界、幂等操作和可回滚变更。
4. 商户自主：租户拥有自己的前台品牌、数据和已验证域名。

## 品牌人格与语气

LONGOS 的表达应专业、清晰、克制、可靠。先说明结果，再提供必要操作；使用“站点”“租户”“域名验证”等准确用语，不使用夸张承诺。错误信息必须告诉用户发生了什么、是否影响数据、下一步如何处理。

中文使用简洁的现代书面语，英文使用 sentence case。产品名始终写作全大写 `LONGOS`，不得写成 Longos、longos 或 LONG OS；代码标识、域名和包名可按技术规范使用小写。

## 身份层级

| 触点 | 必须使用的身份 | 可否由租户修改 |
|---|---|---|
| SaaS 控制面、平台管理端、安装器、CLI、系统邮件 | LONGOS | 否 |
| 租户前台名称、Logo、favicon、配色、SEO | 租户品牌；默认 LONGOS | 是 |
| 平台生成域名与 DNS 验证记录 | LONGOS 规则 | 否 |
| 源码许可证、上游版权声明 | 原权利人名称 | 否 |
| 内部兼容命名空间与事件协议 | 保持兼容名称 | 否，除非完成迁移方案 |

租户自定义品牌不会改变项目归属：控制面仍为 LONGOS，租户只拥有自己的店面表达。合法绑定的自有域名可替换平台生成域名作为主域名，但平台域名的保留或重定向策略由控制面管理。

## 标志

- 主标志：`public/image/longos-logo.svg`
- 网站图标：`public/image/longos-favicon.svg`
- 最小留白：标志四周至少保留字标高度的 25%。
- 最小显示宽度：完整字标 120px；更小空间使用 favicon。
- 禁止拉伸、描边、倾斜、重排字母或添加未经定义的渐变。
- 管理端始终使用 LONGOS 主标志；租户上传的 Logo 仅应用于租户前台。

## 色彩系统

色彩保持在六个基础令牌内；状态色由组件系统按可访问性要求派生。

| 令牌 | 色值 | 用途 |
|---|---:|---|
| LONGOS Blue | `#155EEF` | 主操作、链接、焦点状态 |
| LONGOS Violet | `#6D28D9` | 强调、关键数据、品牌辅助 |
| Ink | `#101828` | 标题与主要正文 |
| Slate | `#475467` | 次要正文和说明 |
| Canvas | `#F8FAFC` | 页面背景 |
| White | `#FFFFFF` | 卡片与反色内容 |

正文与背景对比度至少满足 WCAG 2.1 AA。不可仅依赖颜色表达验证状态、错误或租户生命周期。

## 字体

- 拉丁字母与数字：Jost；不可用时依次回退到 `Segoe UI`、系统无衬线字体。
- 中文：系统无衬线字体；Windows 优先 `Microsoft YaHei`，macOS/iOS 优先 `PingFang SC`。

一个界面最多使用上述两类字体。标题通过字重和字号形成层级，不额外引入装饰字体。

## 文案与命名规则

- 首次出现使用 `LONGOS Commerce SaaS`，后续可简称 `LONGOS`。
- CLI 主命名空间使用 `longos:*`；历史命令仅作为隐藏或明确标注的兼容别名。
- Docker 容器、网络、默认数据库和包元数据使用 `longos` 前缀。
- DNS 所有权验证记录使用 `_longos-challenge`，不得与 TLS 服务商的记录混用。
- 对外不得将 Laravel、Spatie 或 BeikeShop 表述为 LONGOS 品牌名；它们只能出现在技术栈、兼容性或法律来源语境中。

## 法律来源

LONGOS 是本发行版的产品身份，LONGOS 原创代码及修改部分归 LONGOS。项目基于 BeikeShop 演进并依照 OSL-3.0 分发；上游代码、第三方组件、商标和版权仍归各自权利人所有。不得移除源码中的许可证、上游版权或归属声明。面向用户的产品身份统一为 LONGOS，与依法保留的源码来源并不冲突。

变更品牌资产、主色、产品名称、归属口径或白标边界时，必须同时更新本文件、`config/longos.php`、自动化测试和相关用户界面。

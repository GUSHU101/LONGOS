# LONGOS编辑器优化记录

参考 Shopify 的结构面板与预览检查器交互，保留 LONGOS 原生模块、前台 Blade 渲染和 Puck 编辑器。

## 已实现

- 结构面板支持复制、隐藏/显示、上下移动、拖动排序；隐藏后保留全部配置。
- 编辑器产品名统一为 `LONGOS编辑器`，后台入口、页面标题、无障碍名称、备份文件与故障提示保持一致。
- 工作台使用克制的后台工具视觉、清晰分区和统一交互状态；移除装饰性渐变、伪品牌徽章和网格纸效果，窄屏使用可展开的底部编辑面板，核心保存与发布操作不会被挤出视口。
- 插入面板新增按页面约束生成的智能组合，可一键创建高转化首页、品牌叙事首页、商品转化、分类营销与内容故事结构，并作为一次操作撤销。
- 插入模块优先放在当前选中模块后方，沿用当前页面归属；原子操作进入撤销历史。
- 模块操作写入 Puck 历史，支持撤销/重做；排序后保持原模块选中。
- 模块复制更新独立标识；服务端以 Puck 的当前 id 为准，兼容 Puck 自带复制操作。
- 插入面板搜索支持名称、说明、分类及关键词。
- 真实前台 iframe 支持 320/768/1024/1440px 设备宽度与自适应缩放；设备名称和像素宽度同时可见，保存状态变化不再重新挂载 iframe。
- 修复 iframe 跨窗口节点识别，保留同一预览地址的滚动位置，保持已选商品预览上下文。
- 编辑画布拦截链接跳转、表单提交和购物动作，避免预览时污染购物车或离开画布；真实交互通过新窗口检查。
- 预览地址限制为当前店铺同源地址，错误页和跨域预览会显示明确故障状态；快速切页、切商品或连续输入会取消过期的局部预览请求。
- 保存、导入、版本恢复共享串行写入队列；提交时固定数据快照，旧响应不能把更新中的内容标为已保存。
- 草稿使用独立的原子状态包保存页面、页头、页尾和菜单；只有明确点击“发布到线上”才更新顾客可见设置。
- 每次写入携带草稿版本；多人或多窗口编辑发生冲突时停止自动保存，并允许下载本地修改、载入最新草稿或显式覆盖。
- 保存失败保留离页提醒；支持 Ctrl/⌘+S；显示未保存、仅草稿、已同步、离线、会话失效和冲突等独立状态，联网恢复后会自动重试本地未保存内容。
- 每次未完成保存的页面、页头和页尾修改都会在当前浏览器标签中保留受限恢复副本；副本使用防抖写入避免大页面输入卡顿，离页和断网时即时落盘；意外刷新时仅在服务端草稿版本仍一致的前提下自动恢复，成功保存后立即清除。
- 页头与页尾面板等待服务端确认后才显示“已保存”；每次输入都同步暂存到父级草稿，即使在防抖保存前切换面板也不会丢失；保存失败时保留当前表单并提供重试。
- 资源搜索统一防抖、取消和过期响应保护，提供空结果与失败提示。
- 链接、视频、商品选择等重复字段使用 React 稳定唯一标识，避免多个同类模块产生重复 DOM ID；次要操作菜单回归原生 Tab 顺序，不再声明未实现方向键行为的 ARIA menu。
- 发布版本包含完整店铺外观；恢复只替换草稿，确认后再发布，不会直接改动线上店铺。
- 发布改用带模块数、页面数和写入保护说明的确认面板；线上四类设置在事务内写入后立即回读校验，校验失败会完整回滚。
- 历史版本改为发布事务后的独立恢复步骤；历史字段未升级、历史过大或写入异常时，已校验的线上发布不再被回滚，并在编辑器状态区明确提示。
- 所有编辑器请求加入 30 秒超时与可重试的网络错误信息；发布状态与普通自动保存分离，避免发布过程中误离页或重复操作。
- 草稿预览必须同时满足 `design=1` 和后台管理员登录态，公开访客无法通过查询参数看到隐藏/未发布内容。
- 首页、商品页、分类页和内容页统一校验模块投放范围，防止跨页面串模块；插入及复制遵守组件可用页面与数量上限。
- 草稿自动保存不再反复清理配置、视图和应用缓存；发布完成后统一清理一次。
- `settings.value` 升级为 `MEDIUMTEXT`，避免复杂页面、完整草稿和版本历史超过 MySQL `TEXT` 容量。
- 原生功能模块逐项对齐“编辑字段 → 持久化 → 前台渲染”：高级 JSON 只补充扩展属性，不再覆盖较新的可视化字段。
- 全局外观、SEO 和应用嵌入只保留一个“主题”入口；补齐 URL 别名与社交分享特色图，并让字号、页面宽度、模块间距、网格和圆角的编辑器默认值与服务端完全一致。
- 切换应用嵌入时只更新 `enabled`，保留插件已有的参数；插件可通过经服务端白名单过滤的数据字段声明获得原生编辑控件，编辑器不再硬引用任何可选插件的 React 源码。
- 商品、品牌、内容页、标签商品、轮播、权益、评价、优惠和保障集合均同时设置编辑器与服务端上限；商品 ID 去重，超限在选择时明确提示。
- 自定义链接拒绝协议相对地址、脚本协议与反斜杠路径；顶层及卡片/轮播内嵌链接都在持久化边界再次过滤。
- 大型轮播、故事、自动商品及自定义代码不再允许插入商品购买窄栏；支付保障仅能用于商品页，并限制单实例。
- 两种图文轮播加入暂停/播放、键盘和 Swiper 无障碍支持，遵循系统“减少动态效果”，滚动公告副本不再被读屏重复朗读。
- 固定优惠倒计时保存为带店铺时区偏移的时间；无效时间回退为无倒计时，活动过期后禁用优惠码复制。
- 商品、品牌、内容页及轮播等无真实数据时仅在编辑器显示可操作空状态，线上不再产生空白区块。
- 最新商品与热销商品插件纳入同一合格标准：补齐投放/实例约束、背景与宽度透传、空状态、轮播依赖和键盘操作。
- 任意模块模板或数据异常时，首页、商品页、分类页和内容页的装修预览都会保留可识别、可删除的错误块。

## 验证

- `npm run typecheck:builder`
- `npm run test:builder`：15 项浏览器端编辑器断言及发布集成断言；覆盖功能模块字段完整性、多语言往返、串行保存及失败恢复、浏览器本地恢复副本、页头页尾切换保护、插件解耦、预览取消、画布动作保护、离线/会话失效状态、发布请求语义、恢复接口业务错误、跨窗口 DOM 选择、预览 URL、搜索请求竞态，以及草稿到线上四类设置的完整发布。
- `php tests/BuilderCoreAssertions.php`：模块适配与渲染回归，覆盖字段优先级、嵌套数量上限、链接安全、时区、投放约束、轮播可访问性、复制身份与显隐往返。
- `php -l beike/Services/PuckDataAdapter.php`
- `npm run production`：已生成生产静态资源。
- 浏览器使用编译后的真实编辑器与隔离的内存接口验证：预览点击打开设置、复制、隐藏、撤销、商品搜索与插入、编辑保存保留商品目标、手机预览。未操作实际商店数据。

当前 PHP 8.5 环境仅出现 PHPUnit Collision 依赖的 `ReflectionMethod::setAccessible()` 弃用提示；编辑器类型检查、生产构建和完整测试均通过。

## 发布边界

顾客访问始终读取已发布的四类设置。装修器读取并写入 `base.design_draft` 原子状态包，安全预览读取该草稿；发布事务才把完整状态复制到线上设置并创建最多 25 个完整版本。数据库结构升级由 Coolify 新镜像的容器入口在共享锁下自动完成，不要在生产容器中手工执行迁移。

# LONGOS 在线客服

启用插件后，前台会出现在线客服入口，后台侧边栏会出现“在线客服”。会话及消息只保存在当前租户数据库中，不会跨子站共享。客户端和后台使用可配置的自适应轮询，页面隐藏或网络异常时会自动降频。后台打开客服页后会定期发送心跳，访客可看到客服在线状态。

在后台“插件”中点击安装、更新或首次启用 **LONGOS 在线客服** 时，系统会自动执行尚未执行的数据库迁移，无需手工运行命令。生产环境建议将刷新间隔设为 4–8 秒，并使用 HTTPS。

消息提交使用客户端唯一 ID 防止网络重试造成重复消息；历史消息和后台会话列表都支持分页加载，初始化和发送接口已启用租户隔离的限流键和禁止缓存响应。客户收起窗口后仍会低频检查新回复，并在客服按钮上显示未读数。

聊天记录默认保留 1 天，可在插件设置中调整为 1–3650 天。LONGOS 调度器每小时的第 15 分钟执行 `longos:live-chat:prune`；部署时必须持续运行 `php artisan schedule:work`，Docker 部署中由 scheduler 容器负责。清理以会话最后消息时间为准；无消息的空会话使用创建时间。每批最多处理 500 条，并会在删除前重新检查活动时间，避免锁表或误删刚收到新消息的会话。

# LONGOS Global Translate v1.6.0 · 翻译库与任务维护升级

发布日期：2026-11-09  
基于用户提供的 `LongosGlobalTranslate.zip`（v1.5.7）升级，不修改主程序、支付插件或站点订单逻辑。

## 本次直接修复

1. **翻译库可查询**：选择目标语言时，左连接公开原文索引，即使还没生成译文也能看到“未翻译”条目；未生成译文的条目不能被误编辑或误删除。全语言查询仍只返回已存在的翻译行，避免扫描条目与所有语言的笛卡尔积。
2. **批量删除已翻译条目**：翻译库结果表支持本页全选、逐条勾选与批量删除；单次最多 100 条，当前界面每页 25 条；同时删除译文修订记录和所有历史发布快照中对应条目，避免旧版本恢复时重新出现已删除译文。
3. **批量重置语言库**：新增多语言一次性重置。后端重新验证语言清单与精确确认短语；保留原文索引、任务记录、用量台账及审计。整个批次使用同一个数据库事务，并通过租户本地的语言维护锁协调新任务创建/发布；任一受影响语言有活跃/暂停任务或在途领取记录时整批拒绝。
4. **停止任务**：为待执行、排队、扫描、运行和暂停状态增加“停止任务”；不再领取新的任务项，未处理条目标记为取消。已经交给翻译商的调用不能撤回，原请求仍完成保守账务结算；取消后绝不自动发布该任务。
5. **删除任务**：完成或取消的任务可从操作界面删除（后端归档 `archived_at`），仍保存底层任务、请求尝试、计费及审计证据，避免删除任务引发重复扣费、无法追溯等问题。尚有在途请求的任务不能归档。
6. **僵死请求恢复**：主动取消后仍有超过 30 分钟的领取记录，可执行保守恢复；由现有账务恢复逻辑保留“不确定”请求，绝不自动重复发送。
7. **任务状态竞争修复**：队列 worker 在取消操作之后，不能将任务状态重新改回 `running` / `completed`；任务取消后不再触发自动发布。

## 安装与升级

1. 在维护时段备份**各租户数据库和原插件目录**，不要只备份配置文件。
2. 通过 LONGOS 实际安装/部署流程替换插件代码，保持目录名 `LongosGlobalTranslate` 不变。
3. **执行插件数据库迁移**：`Migrations/2026_11_09_000008_add_job_archiving.php` 向当前租户 `lgt_jobs` 表增加可空的 `archived_at` 列，并建立 `lgt_locale_maintenance` 语言维护锁表。每个租户使用对应的独立数据库连接/前缀执行。不要只复制 Blade 页面；新列/表缺失时后台会要求修复 schema。
4. 按 LONGOS 原有正式发布流程更新插件资源，重启相关 PHP-FPM / queue worker，清理应用/Blade/路由缓存。已有 `Static/public/widget.js` 无需本次重新设计，但版本发布要保持代码与静态资源同步。
5. 管理后台进入「翻译库」，选择一个目标语言查询；对照「最近任务与安全状态」测试停止/归档。先在测试子站和测试数据上验证，再逐步扩展到生产租户。

**注意：** “删除译文”是真正清除对应译文及各历史快照条目；因为要求防止从旧版本恢复，这是一种特意允许的发布快照擦除例外，旧版本内容会被部分删减。删除前必须备份；下次扫描/重新翻译可能生成新译文，属于新的管理员主动任务。

## 验收用例（建议先用测试租户执行）

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| A1 | 仅扫描法语原文，不创建翻译；在翻译库选择 FR 查询 | 显示未翻译公开原文；未翻译行的修订、审核与选择框不可用 |
| A2 | 在翻译库查询现有译文，选中两条，执行确认删除 | 两条译文、修订版本和所有历史发布快照中对应条目被删除；原文、API 账务不变 |
| A3 | 从上一页/下一页切换，再删除一页译文 | 只删除本页明确选中的条目，不误删上一页选择 |
| A4 | 同时选择 FR/DE 执行批量重置 | 两语言被完整重置，其他语言和原文不受影响；后台统计刷新 |
| A5 | 批量重置 FR/DE，其中 DE 有 paused/planned/running 任务 | HTTP 422，整个批次零删除；先停止 DE 的任务再试 |
| A6 | 运行中的任务点击“停止任务” | 后续 `ready` 项不再派发，状态稳定为 `cancelled`；队列不会再次改回 running |
| A7 | 取消后立刻删除仍含 claimed 项的任务 | 被阻止，保留用量证据；请求结算后可删除 |
| A8 | 取消的任务拥有超过 30 分钟的僵死 claimed 项 | “恢复超时请求”标记已结束/不确定，绝不重发服务商调用，随后可删除任务 |
| A9 | 删除已完成任务 | 任务从最近列表消失，但 DB 任务、item、attempt、usage、audit 不物理消失 |
| A10 | 删除已发布译文后访问前台、尝试恢复旧版本 | 被擦除的译文不再从当前或旧版本恢复；其他已发布条目仍可正常展示 |
| A11 | 连续提交相同删除、快速并发点击停止/完成 | 幂等取消；已不存在的译文返回可读错误，不允许队列复活已取消任务 |
| A12 | 切换租户重复 A1–A9 | 所有数据操作限定在 LONGOS 活跃租户数据库，不跨子站 |

## 实现边界与部署验证

- 本包仅包含插件源码，**没有生产数据库、主站完整 Laravel 工程或运行中的 queue worker**；无法在当前环境证明所有主程序路由和各数据库方言集成情况。
- 后台 JavaScript 已执行语法解析；需要在有 PHP CLI、LONGOS 和 MySQL/相应租户 DB 的部署环境运行 `php -l`、插件迁移与上述 A1–A12 验收。
- 任务“停止”不等于取消已经到达第三方的 API 请求；那些请求仍可能计费。超时领取只保守标记结果不确定，不会判定为“免费可重试”。
- 若数据库量极大，多语言全量重置会在一个事务中占用较多锁和时间；请在维护窗口执行，并事先确认备份和 SQL 超时设置。
- 没有更改 PayPal、Stripe、LONGOS 代收或订单代码；它们需要独立审计测试。

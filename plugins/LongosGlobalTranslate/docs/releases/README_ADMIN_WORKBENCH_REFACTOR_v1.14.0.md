# LONGOS 全球翻译 v1.14.0：控制面板重构说明

**交付范围**：重构 `Views/admin/index.blade.php` 的信息架构、交互和视觉样式，并修正一项影响快捷任务入口的后台状态同步问题。完整升级包沿用 v1.13.0 的 Cloudflare 国家识别、翻译库批量删除、任务生命周期、服务商删除、硅基流动多免费模型与 RPM/TPM 保护等业务功能。

## 1. 为什么需要这次重构

旧版后台把任务进度、翻译库筛选、人工审核、维护、说明文本放在同一长页中，部分表格仅占半栏却设置很大的最小宽度，需要横向滚动。多个入口依赖用户理解“扫描、翻译、审核、发布”的系统术语，频繁查看参数说明，缺少明确下一步动作。

本次目标：**常用操作一步进入；复杂参数保持可用但默认收起；系统状态成为下一步操作的依据。** 不新增后端权限、不重命名 API、不弱化删除确认与计费保护。

## 2. 新工作台结构

| 一级入口 | 主要任务 | 次要操作 |
| --- | --- | --- |
| **概览** | 四项关键指标、当前建议操作、每种语言的翻译进度 | 展开运行诊断 |
| **翻译与译文** | 二级切换：**任务进度** / **翻译库与审核** | 高级扫描范围、人工修订、词汇保护、整库维护 |
| **发布** | 选择语言并审核发布 | 展开详细发布参数、前台浮窗设置、历史版本回滚 |
| **语言与地区** | 启用目标语言、自动地理匹配、浏览器回退 | 展开国家规则、特定国家语言覆盖 |
| **服务商** | 查看服务商验证/派发状态、额度、编辑和删除 | 添加 API 账户、硅基流动 RPM/TPM、故障转移高级参数 |

概览顶部新增“建议下一步”卡片，会依据最新的服务商派发状态、启用语言、当前任务、已发布词典，提示配置、开始翻译、查看进度、审核发布或维护译文。页面初次加载显示服务端预估建议，后续由动态状态接口校准。

## 3. 功能和交互改动

### 翻译与译文分离

- “任务进度”：默认显示快捷翻译任务、任务列表及按需展开的自定义扫描范围。
- “翻译库与审核”：显示完整宽度的翻译表格、条件筛选、本页批量选择、批量删除、人工修订及高级清理。
- **不再在同一屏幕并排挤压两个不同工作。** 二级切换只改变浏览器显示，不删除数据、不重置选中的待处理内容。
- 首次打开“翻译库与审核”时才请求译文列表，减少无需审核时的额外查询。
- 语言进度卡的“继续翻译”直达任务；“审核译文”直达翻译库并预选目标语言；“发布”直达发布区。
- 可以直接使用地址片段 `#lgt-library-jobs` 和 `#lgt-library-translations` 打开所需视图；旧地址 `#lgt-library` 仍兼容。

### 动态下一步与状态同步

- 修复原面板在用户启用派发后仍把 `dispatchReady` 当作第一次加载时不可变值，导致快捷翻译按钮误报“尚未开启派发”的问题。
- 刷新状态后更新**已验证服务商、已发布语言、进行中任务**指标，以及下一步按钮指向。
- 不再每 8 秒固定请求完整后台状态：有进行中任务时约 **6 秒**刷新；空闲时约 **25 秒**；后台标签页降低请求频率；错误时延长重试间隔。
- 同一时刻避免重复状态请求，减轻 SaaS 多子站后台数据库压力。

### 服务商管理

- 服务商列表上方新增明确的 **“添加账户”** 按钮；点击自动展开表单并清理之前的编辑状态。
- 额度/派发长篇说明改为折叠式“费用与派发规则”，默认不占页面主视图。
- 现有“编辑、验证、开启/关闭派发、删除”保持原接口与原二次确认逻辑。
- 硅基流动多免费模型及 RPM、TPM 字段仍由原账户逻辑控制，未降低安全限制。

### 视觉与易用性

- 主标题、简短状态栏、次级操作按钮，减少层叠式描述。
- 概览采用统一四列指标卡和明显的建议操作；移动设备改为两列。
- 导航可通过左右箭头、Home / End 键切换；每个一级页面都具备对应 tab 与 tabpanel 语义。
- 翻译库表格改为完整宽度；小屏幕仍允许必要的横向滚动。
- 保留明显的红色危险操作与原有服务端确认，不用“视觉简化”掩盖删除后果。

## 4. 后端契约与安全保证

本次没有调整：

- 翻译内容来源和装修模块字段白名单，SEO 元数据仍不参与翻译；
- Cloudflare 可信国家校验及按子站发布词典自动本地化；
- 原始语言、已启用语言和已发布语言的约束；
- 计费额度、硅基流动模型请求数/Token 限流；
- 服务商删除归档、任务取消、超时恢复、翻译库删除和发布版本回滚的后端规则。

**这次改的是管理工作流，不是数据库或资金敏感操作的实现。** 所有危险动作仍走原 Laravel 服务端权限、验证和审计。

## 5. 技术文件

| 文件 | 变化 |
| --- | --- |
| `Views/admin/index.blade.php` | 主体 UI、可访问导航、工作区拆分、账户快捷入口、状态与轮询机制 |
| `Tests/verify_source_contracts.mjs` | 增加导航面板关联、子视图切换、控件 ID 存在性和状态刷新契约检查 |
| `config.json` | 发布号更新 `v1.14.0` |
| `Services/StorefrontPresentationConfig.php` | 前端/后端版本对齐 `1.14.0` |
| `Static/public/widget.js`、`Views/shop/widget.blade.php` | 浏览器资源版本统一 `1.14.0`，避免升级后静态资源缓存不一致 |

**无新增 SQL migration**，无需重新清空任何翻译库、翻译任务或服务商账户。

## 6. 验证与验收

已在代码工作区执行 `node LongosGlobalTranslate/Tests/verify_source_contracts.mjs` 和 JavaScript 语法解析验证；ZIP 生成后还需要执行压缩包完整性检查。

当前环境没有 PHP CLI/Laravel 主应用与真实商家数据，浏览器图形渲染环境也未能启动，因此 **不能声称完成真正的生产页面验收**。部署预发布站后必须至少人工走查：

1. 初次打开概览，5 个导航页可以切换，浏览器地址和键盘导航正常；手机端按钮不遮挡操作。
2. 添加服务商、验证、开启派发后，“开始翻译”不再引用页面初始旧状态。
3. 翻译工作区从任务切换到译文时完整宽度显示翻译表格；语言进度卡“审核译文”正确跳转并筛选。
4. 批量选择 25 条中的部分译文、批量删除、人工修订、批准、发布与回滚接口结果与旧版一致；**仅在测试数据上验证删除功能**。
5. 服务商编辑、模型切换、RPM/TPM、额度变化、验证、删除保留安全确认。
6. 运行中任务时状态约 6 秒刷新，空闲减少轮询；多子站操作不串配置、语言库、服务商或任务。
7. Cloudflare 国家识别与前台语言浮窗功能无版本不匹配警告，插件 CSS/JS 已发布同步。

建议先备份插件目录，在预发布环境完整替换 `LongosGlobalTranslate/`，执行 LONGOS 常规插件资产发布流程后，再逐站灰度上线。

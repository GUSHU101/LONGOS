# v1.18.1 — SaaS 跨租户免费模型限流加固

## 已修复

- SaaS 模式下硅基流动 RPM/TPM 和 429 冷却状态改由 LONGOS 控制面集中保存。相同计费身份标签（大小写敏感）+ 模型跨子站共享数据库行锁、滚动窗口和调用额度。不同租户的设置若不一致，中央账户在运行中只会收紧限额，不会被较宽松的设置自动放大。
- 每个站点仍独立加密 API Key、保存翻译库和发布词典；控制面只保存计费身份摘要、模型名称、速率配置和 token 预约计数，不包含密钥及文本。
- 中央表缺失时抛出 `SAAS_TRANSLATION_RATE_TABLES_MISSING` 并停止派发，禁止回退到各站本地独立计数。非 SaaS 单站仍使用旧本地速率表。
- 新增双租户回归用例：两个不同租户的不同本地账户 ID，使用相同远程计费标签，应共享 RPM 窗口；释放预约可恢复额度；中央表缺失时失败关闭。

## 升级注意

1. 通过常规 Git + Coolify 部署；`saas:upgrade` 自动运行控制面迁移 `database/migrations/2026_11_10_000001_create_saas_translation_rate_limits.php`，不要在生产容器手工迁移。
2. 同一硅基流动官方用户在不同子站配置多个 API Key 时，**必须**使用相同的“计费身份”文本。不同标签无法自动证明属于同一远程用户，可能削弱合并限流。
3. 新中央窗口从部署时开始累计。部署前暂停翻译并等待在途请求结束，恢复后先以低并发验证。
4. 限流迁移及并发用例目前需要 PHP/Laravel、真实数据库环境完成验证；源码静态检查不代表生产验收。

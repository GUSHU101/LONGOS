# LONGOS Global Translate v1.6.1 · 后台交互精简升级

基于 v1.6.0 的功能修复版继续升级。此次重点解决后台操作繁琐、内容堆积、用户找不到关键操作的问题。**没有删掉底层功能，也没有伪造智能决策。**

## 新的信息架构

| 主导航 | 主要用途 | 默认可见内容 |
| --- | --- | --- |
| 概览 | 看全局运行状态与下一步 | 3 个关键数字、各语言翻译/发布进度、具体操作按钮 |
| 翻译与任务 | 创建任务、看队列、审核/删除译文 | 一键扫描并开始、任务表（停止/归档/安全重试）、翻译库筛选和批量操作 |
| 发布 | 发布可用译文、查看历史版本 | 语言选择、审核并发布、历史版本列表 |
| 语言设置 | 设置源语言、可展示语言、匹配策略 | 语言列表和保存按钮；复杂国家规则折叠 |
| API 账户 | 查看可用额度、验证/编辑服务商 | 账户列表优先；添加/编辑表单按需展开 |

不再把五个导航项描述成必须逐个完成的“引导步骤”。重复的扫描表单、独立任务创建表单、术语保护词、全库重置、发布细节和诊断统一按需展开。

## 行为改善

- 「扫描并开始」自动跳过已有有效译文，完成创建后停留在有实时任务状态的**翻译与任务**页，不再错误跳转到发布页。
- 如果尚未保存语言、非免费派发模式或未授权 API，给出直接的配置提示并跳到对应设置页；不会假装已经开始翻译。
- 任务列表显示短任务编号，悬停可查看完整 ID；仍显示失败原因、取消、归档、在途请求与安全重试。
- 各语言进度卡只展示“已翻译/总数”和“已发布”两个主要指标；操作按钮根据状态指向翻译库或发布页，并自动选择相应语言。
- 语言与服务商的次要表单说明只在输入项获得焦点时展示，减少整屏辅助文本。
- 服务商已有账户时，账户表优先显示；点击编辑会自动展开表单。
- 当前页签保存在页面地址的片段中，保存服务商后刷新会回到原位置，不再无端跳回概览。
- 自检信息收纳到概览的「诊断与运行状态」，摘要保留异常数量；不再占据常规操作页面的首屏。
- 危险操作仍有显式确认，不为了减少点击而绕过数据删除与计费安全保护。

## 验收重点

1. 概览、翻译与任务、发布、语言设置、API 账户五个页签可正确切换，且任一时间仅有一个主面板可见。
2. 在概览某语言卡片点击“继续翻译/审核译文”，应切换到翻译库并选中该语言；点击“发布”应带入发布语言。
3. 进入「翻译与任务」后，不需要点开高级设置即可看到翻译任务列表、停止/删除任务按钮以及译文库。
4. 点击「自定义扫描和任务范围」后，原扫描和自定义计划表单仍可提交，关闭后不影响默认一键流程。
5. 执行一键扫描后留在「翻译与任务」，能自动刷新进度，**不能**在任务仍排队时跳到发布页暗示已完成。
6. 没有有效 API 授权时，点击一键开始应停在操作前并进入 API 账户设置，不会创建无法真正运行的任务。
7. 已配置 API 账户时表单默认折叠；点击该账户的编辑按钮，必须自动展开并带入非敏感额度设置，旧密钥依然不回显。
8. 发布页的快速发布、历史快照回滚、展开后的高级发布/前台选择器设置都正常。
9. 语言设置、国家自动匹配高级配置、批量删除译文、清空语言库、保护词、人工修订均保留。
10. 在 360px–768px 屏宽下，导航可以横向滚动、卡片完整换行、表格可滚动；不得把操作按钮压到屏幕外而不可访问。
11. 结合 v1.6.0 的 A1–A12 回归用例，验证源语言不可删除、取消后不复活任务、审计与计费记录完整。
12. 在实际 LONGOS 租户后台验证页面渲染、CSRF、权限隔离和真实 PHP/Laravel 行为。

## 部署

这是完整插件 ZIP，包含 v1.6.0 的功能修复和 v1.6.1 的交互改进，**不是只有页面差异的补丁**。若从更旧版本直接升级，请先执行 v1.6.0 升级说明中的数据库迁移。更新后清理 Blade/路由缓存并让队列 worker 加载新代码。

当前工作区通过了后台 JS 语法、功能路由静态关联、HTML 结构检查和 ZIP 完整性验证。缺少实际 LONGOS 主程序、PHP CLI、租户数据库和可用服务商凭据，因此上述端到端验收**尚未执行**。正式上线前务必在测试子站验证，并保留原插件与租户数据库备份。

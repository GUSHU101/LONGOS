# LONGOS Global Translate v1.9.0 — 硅基流动免费 AI 翻译接入

> 历史版本说明：v1.9.0 仅允许 Hunyuan-MT-7B。若使用 v1.9.1 或更新版本，请以 `README_SILICONFLOW_MULTI_FREE_MODELS_v1.9.1.md` 为准，其中新增免费模型选择与免输密钥切换。

发布日期：2026-11-09

本包为完整插件升级包，在 v1.8.0 的服务商删除、v1.7.0 的并发与计费状态修复、v1.6.0 的翻译库批量清理及任务取消、v1.6.1 的后台精简基础上，新增 **SiliconFlow（硅基流动）** 作为第七种翻译服务商。不会专门绑定手机壳品类，继续处理本 SaaS 租户公开站点内容。

## 功能与使用方式

1. 在硅基流动控制台创建个人或组织自己的 API Key（本插件不提供公共共享密钥）：<https://cloud.siliconflow.cn/>。
2. **先打开官方价格中心** <https://siliconflow.cn/pricing>，核实 `tencent/Hunyuan-MT-7B` 仍标示免费，且当前账户有权调用。模型可用性、实名认证和限流以官方账户状态为准。
3. LONGOS 后台进入「全球翻译 → API 账户 → 添加或编辑 API 账户」，选择「硅基流动（免费 AI 翻译）」。
4. 输入一个不重复的账户标识与 API Key。模型字段自动固定为 `tencent/Hunyuan-MT-7B`，只读，**无需人工输入模型 ID，也不能选择付费模型**。
5. 初次切换到硅基流动时，界面会建议本地免费字符预算 100,000、安全上限 90,000、1 QPS；这些是保护性**本地配置值，不是硅基流动官方额度**。管理员可以修改。
6. 保存后账户默认不开启派发。点击「验证账户」进行一次小型 `en → fr` 请求；验证成功后点击「开启派发」。开启前再次核对官方价格。
7. 在「语言策略」启用目标语言并选择「仅使用免费额度」，再创建翻译任务。成功译文进入原有翻译库与审核/发布工作流，原有缓存、任务删除和翻译库批量删除机制不变。

## 与现有插件集成

| 项目 | 行为 |
| --- | --- |
| 后端 API | 固定 `POST https://api.siliconflow.cn/v1/chat/completions`，Bearer API Key，非流式调用 |
| 模型 | 服务器端仅允许 `tencent/Hunyuan-MT-7B`；前端和服务端均限制模型变更 |
| 私密信息 | API Key 使用既有 Laravel Crypt 加密保存；浏览器、公开前台和状态接口不返回密钥 |
| 翻译输入 | 仅发送由原有内容扫描器允许的公开站点文案和固定翻译上下文；不扩大订单、支付或访客数据范围 |
| 任务与计费台账 | 使用既有单条分段、账户优先级、QPS、本地字符额度、请求尝试与 `reserved/sending/committed/uncertain` 状态 |
| 失败处理 | 无效输入、认证/权限错误、余额不足和限流有明确代码；输出为空或被截断不会视为成功，并按保守原则计入不确定状态 |
| 故障转移 | 不会从 Hunyuan-MT-7B 自动切换到该服务商的收费模型；既有跨服务商故障转移配置仍由管理员决定 |
| 服务商删除 | 仍可从 API 账户列表删除硅基流动账户；先安全停止派发、清除加密密钥，保留必要的计费/审计历史 |
| 多租户 | 复用插件现有账户、翻译库、任务和发布范围，未新增共享租户凭据或全局默认密钥 |

### 非零成本保证的边界

- 硅基流动官网价格中心在本次开发时将 `tencent/Hunyuan-MT-7B` 的输入和输出列为免费。**这是当前公开标价，不是永久免费承诺**，服务商可能调整价格、权限或免费条件。
- 免费模型也可能受并发与速率限制；本插件不会绕过官方限流，不以多个账户规避规则。
- 本地“免费字符额度”只控制插件可发送的文字规模，**不能实时读取或冻结供应商账户的实际人民币费用**。请用供应商账单、限额或消费提醒进行额外保护。
- 既有配置中如存在其他服务商账户，故障转移可依次尝试它们；是否真正免费取决于对应服务商的套餐与外部用量。若只允许硅基流动，请将其他服务商关闭派发。
- 本版本未接入 SiliconFlow `/v1/models` 价格判断：官方模型列表不携带定价字段，客户端无法据此断言当前费用为零。**每次启用前人工核对官方价格**。

## 安装升级

1. 备份原插件目录、相关 SaaS 租户数据库、队列/配置及正在使用的翻译 API 账户。
2. 在测试环境通过 LONGOS 原有插件部署链路替换整个 `LongosGlobalTranslate` 目录；不要只替换新增 Provider 文件。
3. 如果从 v1.7.0 或更早版本直接升级，需要依序执行旧版升级包文档中的数据库迁移。**v1.9.0 本身不增加迁移文件**。
4. 按项目已有正式流程清除 PHP 应用/Blade/路由缓存，重启 PHP-FPM 和队列 worker，验证后台版本 `v1.9.0` 与静态资源一致。
5. 仅用测试租户和测试 API Key 检查请求，确认余额/价格、质量审核和前台发布正常，再向其他租户推广。

## 验收用例

| 编号 | 验证步骤 | 预期结果 |
| --- | --- | --- |
| SF1 | 新增硅基流动账户，不填 API Key | 前端表单阻止保存；后台也拒绝空密钥 |
| SF2 | 试图通过构造接口将 `model` 改为任意收费模型 | 服务端拒绝保存；运行时 Provider 也拒绝非固定模型 |
| SF3 | 新增正确 API Key 与本地额度，保存 | 加密保存、不立即发起请求，派发关闭 |
| SF4 | 验证账号后开启派发，翻译一段英文公开商品描述到法文 | 出现一条译文且完成原有文本格式与翻译质量检查 |
| SF5 | 编辑账户只修改 QPS/额度，Key 保持空 | 不更换密钥、不清除验证状态；模型预填不会触发密钥轮换 |
| SF6 | 编辑账户输入新的完整 API Key | 进行凭据轮换，需要重新验证才能派发 |
| SF7 | 使用无效 API Key、无权限模型、超频 429 | 失败原因被记录，不发布伪译文；无无限重试或收费模型回退 |
| SF8 | 模型返回 `finish_reason=length` 或空文本 | 拒绝作为成功译文并按可能已发送的尝试安全保留记录 |
| SF9 | 硅基流动账户存在在途请求时尝试删除 | 按旧版服务商删除保护规则拒绝；无在途请求才可归档清钥 |
| SF10 | 两个租户配置不同 API Key 和翻译任务 | 租户之间没有共享密钥、任务、翻译结果或额度 |
| SF11 | 停止任务、批量删除译文、删除该服务商账户 | 原有的任务取消、翻译库维护与账户安全归档功能仍可使用 |

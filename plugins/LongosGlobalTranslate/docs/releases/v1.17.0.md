# v1.17.0 — 免费模型限制模型重构

## 修复

- 硅基流动当前免费模型改为 `rate_only` 预算模式，不再使用人为的 100,000 / 90,000 字符上限。
- 既有硅基流动账户在迁移时自动改为仅速率模式；旧额度字段作为历史/降级兼容保留但不再执行，已记录的调用与审计计数不变。
- RPM、TPM 和 429 冷却从“子站全局模型”修正为“硅基流动用户账户 + 模型”独立窗口；不同用户不再相互占用，同一用户的多个 Key 应复用同一条账户记录。
- 移除硅基流动上的通用 QPS 节流，避免默认 `1 QPS` 将官方 `1000 RPM` 人为压低为约 `60 RPM`；配置的 RPM/TPM 现在是唯一分钟总上限。
- 官方限流实体是“用户账户”而非 API Key；同一硅基流动用户的多个 Key 必须复用同一条 LONGOS 账户记录。
- 账户界面在仅速率模式下隐藏无意义的字符额度，改为展示 RPM、TPM、QPS 与处理用量。

## 安全边界

- `rate_only` 由服务端根据服务商派生，管理页无法将付费服务商伪装为无上限。
- 翻译请求仍经过持久化预留、发送和结算状态；字符计数只不再作为硅基流动的派发门禁。
- 免费模型列表是本版本发布时的官方定价快照，不宣称永久免费；运营者应在官方定价变更后重新核对。

## 验证

- 新增回归测试覆盖零字符额度派发、用量审计、账户级速率隔离与 429 冷却隔离。

# v1.16.0 — 并发与发布完整性加固

## 变更

- 修复多翻译 worker 并发暂停竞态：尚未跨过外部发送边界的领取项会安全回到 `ready`，不会被误记为取消并从恢复任务中永久丢失。
- 保留计费安全：如果同一字段已有片段被服务商接受，任务停止后不会重放整个字段，而是标为需要人工复核。
- 管理工作台新增硅基流动速率窗口和部分片段中断的可操作说明。
- 插件版本、店面资源缓存键和配置契约统一为 `1.16.0`。
- GitHub CI 将 LongosGlobalTranslate 纳入 release-owned 源码门禁，防止插件目录再次被意外删除。
- 根目录只保留当前主说明，旧版本文档统一移入 `docs/releases`。

## 验证重点

- 并发暂停发生在领取之后、服务商发送之前时，请求次数必须为零，条目恢复为 `ready`，任务完成/失败计数保持不变。
- 已知未发送的账本尝试必须进入 `definite_failed`，不得留下 `reserved` 或 `sending` 占用。
- 真正的管理员取消仍然终结条目；恢复性暂停不得被当作取消。

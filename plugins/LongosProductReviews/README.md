# LONGOS Product Reviews

LONGOS 商品评论插件为每个商品提供独立的星级、图片和图文评论管理，并将已发布评论展示在商品详情下方。

## 使用

1. 新建 SaaS 租户会自动安装数据表并启用插件。
2. 现有站点在正常发布升级时会自动补登记并迁移 **LONGOS Product Reviews**；已存在的启停状态和每次显示数不会被覆盖，无需为每个租户手工执行数据库命令。
3. 从后台“商品评论”菜单添加、编辑、发布或删除评论。
4. 也可以在商品列表或商品编辑侧栏快速进入对应商品的评论管理。

评论图片使用租户隔离的上传目录，删除评论时会同步删除属于该租户的评论图片。前台仅输出“已发布”评论，并对评论文本进行 HTML 转义。

## 免费 AI 批量演示数据生成（SiliconFlow）

后台「商品评论」页新增「AI 批量生成演示评论记录」区域：

1. 在 https://cloud.siliconflow.cn/account/ak 创建 API Key，并在**对应租户站点**的商品评论页面保存；密钥使用 Laravel Crypt 加密存储，页面不回显。
2. 选择「商品 ID」、「分类 ID」（均可留空，留空选择最近启用的商品）、本批商品数量（1–50）、每商品条数（1–5）和语言。
3. 点击「开始批量生成草稿」。使用 `XingChenAGI/Xing4.0-29B` 免费模型，走硅基流动 OpenAI 兼容 Chat Completions 接口，不自动回退收费模型。
4. 现有 `default` 队列 Worker 顺序处理本批商品任务，页面刷新可查看完成数、草稿数和失败统计。429/503 采用少量限次重试。
5. 每条 AI 记录包含**模拟姓名、模拟国家、演示星级、标题、正文以及用于页面排序的模拟日期**。图片为空，无法凭文字生成真实顾客图片；记录带不可变 `ai_generated` 标记，强制 `published=false`、`verified_purchase=false`，禁止通过原有发布操作发布为真实评论。显示「AI 演示数据」标记。
6. API Key、SQL 数据和异步队列上下文均按已生效的租户隔离；模型价格、是否仍免费、可用性、速率限制以硅基流动官方实时信息为准。

**重要：** 此功能仅为站内布局测试与内部文案草稿辅助，不是购买后真实用户反馈。不要移除演示标记、伪造已验证购买状态或把虚构身份作为真实顾客证言。已有真实评论继续通过原有入口管理；对真实客户反馈进行 AI 编辑时应保留真实姓名、国家、原始评分和实际评论日期。

# LONGOS Product Reviews

LONGOS 商品评论插件为每个商品提供独立的星级、图片和图文评论管理，并将已发布评论展示在商品详情下方。

## 使用

1. 新建 SaaS 租户会自动安装数据表并启用插件。
2. 现有站点在正常发布升级时会自动补登记并迁移 **LONGOS Product Reviews**；已存在的启停状态和每次显示数不会被覆盖，无需为每个租户手工执行数据库命令。
3. 从后台“商品评论”菜单添加、编辑、发布或删除评论。
4. 也可以在商品列表或商品编辑侧栏快速进入对应商品的评论管理。

评论图片使用租户隔离的上传目录，删除评论时会同步删除属于该租户的评论图片。前台仅输出“已发布”评论，并对评论文本进行 HTML 转义。

# LONGOS Product Reviews

LONGOS 商品评论插件为每个商品提供独立的星级、图片和图文评论管理，并将已发布评论展示在商品详情下方。

## 使用

1. 新建 SaaS 租户会自动安装数据表并启用插件。
2. 现有站点在正常发布升级时会自动补登记并迁移 **LONGOS Product Reviews**；已存在的启停状态和每次显示数不会被覆盖，无需为每个租户手工执行数据库命令。
3. 从后台“商品评论”菜单添加、编辑、发布或删除评论。
4. 也可以在商品列表或商品编辑侧栏快速进入对应商品的评论管理。
5. “AI 批量生成”中配置硅基流动 API Key 与模型，测试连接后可按商品、数量、日期范围、星级范围与分布、评论篇幅、国家/地区池和示例评论提交后台生成任务。日期会分层抽样、国家/地区会均衡轮换，并为每条评论分配不同写作角度，减少成批内容的机械感。
6. 生成页和商品评论页都会显示当前管理员最近的生成任务并轮询后台进度；离开页面不会中断任务，重新进入时会自动恢复进行中或已完成待确认的批次，也可主动取消。相同管理员对同一商品的进行中任务会被复用，避免双击或浏览器重试导致重复请求与计费。评论生成使用独立 `product-reviews` 队列和默认 3 个工作进程，不占用翻译队列的工作进程；单个批次会按 10 条分组，在已配置的模型池中轮询并行请求，再执行跨分组去重后合并。
7. 生成参数与预览结果均加密暂存 7 天，过期后由后台定时任务自动清理。预览可逐条取消勾选；生成完成后需确认保存，选中项才会作为“未发布 + 未验证购买”草稿进入评论列表。发布后前台会在评论正文尾端以普通文字追加“商家提供内容”，不再显示独立徽标或提示行；生成内容无法设为已验证购买。
8. 评论列表支持当前页全选或逐条勾选，批量设置人工评论的购买验证状态，以及所有评论（包括生成草稿）的人工审核状态。

硅基流动 API Key 按租户使用 Laravel `Crypt` 加密保存，密钥留空重新保存时会保留原值。请求仅发往固定的 `https://api.siliconflow.cn/v1` 端点，使用 JSON 模式并验证返回结构。保存配置或测试连接时会从官方模型市场识别当前模型的 L0 RPM/TPM，缓存 24 小时，并按 API Key + 模型在所有队列进程间统一限速；实际派发保留 10% 安全余量，官方页面暂时不可用时使用已缓存值、内置已知值或保守上限。模型输出对象只允许 `author_name`、`title`、`body` 三个字符串字段；星级、国家/地区、时间和内部匹配 ID 均由服务器生成，任何来源、联系方式、标签、备注或其他额外字段都会使该组输出被拒绝。客户端对网络超时、429 和 5xx 短暂故障执行带抖动的指数退避，识别服务端 `Retry-After`，并将未完成任务重新入队而不立即标记失败；截断、空响应、无效 JSON、缺项、重复与安全校验失败的输出会带修正提示再生成一次。统一内容策略会在模型返回、草稿落库、后台编辑和发布四个阶段复检作者、标题与正文，拦截 AI/机器生成、商家/卖家生成、示例、虚构、占位、草稿、推广或赞助等创作过程说明，同时检查精确重复、近似重复、重复作者、联系方式、富文本标记与多语言“已验证购买”声明。前台仍保留真实来源披露，避免把商家生成内容误导为真实顾客评价。默认模型的免费状态可能随官方计价调整，后台会保留可配置的精确模型 ID。

评论图片使用租户隔离的上传目录，删除评论时会同步删除属于该租户的评论图片。前台仅输出“已发布”评论，并对评论文本进行 HTML 转义。

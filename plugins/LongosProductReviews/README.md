# LONGOS Product Reviews

LONGOS 商品评论插件为每个商品提供独立的星级、图片和图文评论管理，并将已发布评论展示在商品详情下方。

## 使用

1. 新建 SaaS 租户会自动安装数据表并启用插件。
2. 现有站点在正常发布升级时会自动补登记并迁移 **LONGOS Product Reviews**；已存在的启停状态和每次显示数不会被覆盖，无需为每个租户手工执行数据库命令。
3. 从后台“商品评论”菜单添加、编辑、发布或删除评论。
4. 也可以在商品列表或商品编辑侧栏快速进入对应商品的评论管理。
5. “AI 批量生成”中配置硅基流动 API Key 与模型，测试连接后可按商品、数量、日期范围、星级范围、国家/地区池和示例评论提交后台生成任务。页面会轮询进度，可安全离开并通过带批次 ID 的原链接返回。
6. 生成参数与预览结果均加密暂存，过期后由后台定时任务自动清理。预览可逐条取消勾选；确认后仅把选中项保存为“未发布 + 未验证购买”草稿，发布后前台使用“商家提供内容”标识。生成内容无法设为已验证购买。
7. 评论列表支持当前页全选或逐条勾选，批量设置人工评论的购买验证状态，以及所有评论（包括生成草稿）的人工审核状态。

硅基流动 API Key 按租户使用 Laravel `Crypt` 加密保存，密钥留空重新保存时会保留原值。请求仅发往固定的 `https://api.siliconflow.cn/v1` 端点，使用 JSON 模式并验证返回结构。客户端对网络超时、429 和 5xx 短暂故障执行有上限的退避重试，对重复/缺项的模型输出再生成一次，并与当前商品已有评论做精确去重。默认模型的免费状态可能随官方计价调整，后台会保留可配置的精确模型 ID。

评论图片使用租户隔离的上传目录，删除评论时会同步删除属于该租户的评论图片。前台仅输出“已发布”评论，并对评论文本进行 HTML 转义。
